## HCM_Core 소개

헬스커넥트 모바일 개발에 사용되는 Core 라이브러리 입니다.  
아래의 기능을 지원합니다.
- Bluetooth
- API 통신
- Local DB (Hive)



## 개발 환경 설정
pubspec.yaml > dependencies에 해당 코드를 추가합니다.
```yaml
  hcm_core:
    git:
      url: https://github.com/hconnectdx/hcm_core.git
      ref: 0.0.1 #(해당하는 버전)
```
